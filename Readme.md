# Parking Manager - система управления парковкой

Система управления парковкой с многопоточным сервером и TCP-клиентом. Поддерживает различные типы транспортных средств, почасовую тарификацию и параллельную обработку клиентских подключений.

## Основные возможности

- Многопоточная обработка клиентов с потокобезопасной синхронизацией через мьютексы
- Поддержка трех типов транспортных средств: легковые (размер 1.0), мотоциклы (размер 0.5), грузовые (размер 2.5)
- Гибкая конфигурация парковочных мест через текстовый файл
- Почасовая оплата с округлением времени стоянки вверх (каждая начатая минута считается за час)
- Сетевое взаимодействие через TCP-сокеты с использованием библиотеки SFML Network
- Юнит-тестирование с использованием библиотеки doctest

## Структура проекта

Проект состоит из следующих основных компонентов:

**ParkingSpot** - класс, представляющий отдельное парковочное место. Хранит размер места, состояние занятости, госномер припаркованной машины и время въезда.

**ParkingLot** - главный класс управления парковкой. Содержит вектор парковочных мест, общую выручку, почасовой тариф и мьютекс для синхронизации потоков.

**parking_server.cpp** - TCP-сервер, который принимает подключения клиентов и создает отдельный поток для обработки каждого клиента.

**parking_client.cpp** - консольный клиент для взаимодействия с сервером.

## Требования для сборки

- CMake версии 4.1 или выше
- C++20 совместимый компилятор 
- Git (для автоматической загрузки зависимостей)

## Сборка проекта

Откройте терминал в корневой директории проекта и выполните следующие команды:

```bash
cd cmake-build-debug 
cmake ..
cmake --build .
```
После успешной сборки в директории cmake-build-debug появятся исполняемые файлы parking_server, parking_client и parking_tests.

## Настройка парковки

Перед запуском сервера необходимо создать конфигурационный файл config/parking_config.txt. В этом файле нужно указать размеры парковочных мест. Каждое значение записывается с новой строки или через пробел. Пример содержимого файла:

```bash
1.0 1.0 0.5 2.5 1.0
```

В этом примере создается пять парковочных мест: два легковых (размер 1.0), одно место для мотоцикла (размер 0.5), одно грузовое (размер 2.5) и еще одно легковое.

## Запуск сервера

После сборки запустите сервер из директории cmake-build-debug:

```bash
./parking_server
```

Сервер запустится на порту 8080 и будет ожидать подключения клиентов. В консоли сервера будет отображаться информация о подключенных клиентах и поступающих запросах.

## Запуск клиента

В другом окне терминала из директории cmake-build-debug выполните:

```bash
./parking_client
```

Клиент запросит IP-адрес сервера. Если сервер запущен на том же компьютере, введите "127.0.0.1" или "localhost". После успешного подключения вы увидите список доступных команд.

## Команды клиента

- ENTER <номер> <тип> - заезд машины на парковку. Параметр номер - это государственный номер транспортного средства (строка без пробелов). Параметр тип может быть car (легковой), moto (мотоцикл) или truck (грузовик). При успешном заезде сервер вернет номер парковочного места.

- EXIT <номер> - выезд машины с парковки. Указывается государственный номер машины. Сервер рассчитает стоимость парковки (время стоянки в часах, округленное вверх, умноженное на почасовой тариф) и вернет сумму оплаты и общую выручку парковки.

- STATUS - получить текущее состояние парковки. Сервер вернет количество свободных мест и общую выручку на данный момент.

- QUIT - отключиться от сервера и завершить работу клиента.

## Пример работы с клиентом

Вот как выглядит типичная сессия работы с клиентом:

```bash
=== PARKING CLIENT ===
Enter server IP: 127.0.0.1
Connected to server!

Commands:
  ENTER <plate> <car|moto|truck>
  EXIT <plate>
  STATUS
  QUIT

> ENTER A123BC car
OK SPOT 1
> ENTER B456CD truck
OK SPOT 4
> STATUS
STATUS free=3 revenue=0
> EXIT A123BC
OK TIME 1h COST 100 REVENUE 100
> QUIT
Disconnected
```

В этом примере сначала заехала легковая машина A123BC и заняла место 1. Затем заехал грузовик B456CD и занял место 4. После проверки статуса парковки (свободно 3 места) первый автомобиль выехал. При выезде стоимость составила 100 рублей (предполагается, что машина простояла 1 час по тарифу 100 рублей/час), и общая выручка парковки стала 100 рублей.

## Тестирование

Проект полностью покрыт модульными тестами с использованием doctest. Проверяется корректность работы кода, обработка пограничных сценариев и устойчивость системы к многопоточным нагрузкам.

### Запуск тестов

Для проверки корректности работы базовой логики выполните в директории cmake-build-debug:

```bash
./parking_tests
```

### Что проверяют тесты
- Управление местами — инициализация парковки, создание мест и подбор места под размер ТС.
- Жизненный цикл ТС — въезд машины, успешная парковка, выезд и освобождение места.
- Финансовый учет — округление времени стоянки, расчет стоимости и накопление выручки.
- Конфигурация — загрузка конфигурационного файла и инициализация параметров системы.

#### Обработка ошибок

- Блокировка повторной парковки на уже занятое место.
- Запрет на въезд автомобиля с уже существующим в системе номером.
- Выброс исключений при попытке освободить пустое место.
- Обработка отказа в парковке при отсутствии свободных мест нужного размера.
- Обработка ошибок при выезде несуществующего автомобиля.
- Защита от сбоев при отсутствии файла конфигурации.

#### Граничные случаи 
- Инициализация системы через абсолютно пустой файл конфигурации.
- Циклический сценарий: мгновенное освобождение места и его повторное занятие.

#### Тестирование многопоточности 
- Симуляция 10 одновременных запросов на въезд.
- Проверка корректности синхронизации потоков и защиты критических секций через std::mutex.

## Конфигурация сервера

Настройки сервера находятся в файле src/parking_server.cpp в функции main. Вы можете изменить следующие параметры:

- configPath - путь к файлу конфигурации парковочных мест (по умолчанию "../config/parking_config.txt")
- hourlyRate - почасовой тариф в рублях (по умолчанию 100)
- port - порт для прослушивания подключений (по умолчанию 8080)

### Как это работает

При запуске сервер загружает конфигурацию парковки из файла, создавая указанное количество парковочных мест с заданными размерами. Затем сервер начинает прослушивать указанный порт. При подключении нового клиента сервер создает отдельный поток для его обработки, что позволяет одновременно обслуживать несколько клиентов.

Вся работа с парковочными местами защищена мьютексом - это гарантирует, что два клиента не изменят данные одновременно (например, не займут одно и то же место). При въезде машины сервер ищет первое свободное место, размер которого не меньше размера транспортного средства. Если место найдено, запоминается время въезда. При выезде вычисляется разница между текущим временем и временем въезда, переводится в часы (секунды / 60, так как каждая минута считается за час) и округляется вверх. Стоимость получается умножением часов на почасовой тариф.

## Зависимости

Проект использует две внешние библиотеки, которые автоматически загружаются через CMake FetchContent:

- SFML версии 2.6.1 - используется только модуль Network для TCP-сокетов
- doctest версии 2.4.11 - используется для модульного тестирования

Вам не нужно устанавливать эти библиотеки вручную - CMake скачает их при первой сборке.
