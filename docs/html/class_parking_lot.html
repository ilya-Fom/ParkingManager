Detailed Description

Главный класс управления парковкой

Содержит вектор парковочных мест, общую выручку, почасовой тариф и мьютекс для синхронизации потоков. Реализует многопоточный доступ с блокировками.

Обработка въезда машины

Parameters
vehicleNumberГосномер машины
vehicleSizeРазмер ТС (1.0, 0.5, 2.5)
SpotId[выходной] Номер места, которое заняла машина
Returns
true если место найдено и машина припаркована
false если нет места или машина уже на парковке

Алгоритм:

  1. Захватывает мьютекс (блокирует доступ других потоков)
  2. Проверяет, не припаркована ли уже машина
  3. Ищет первое свободное место подходящего размера
  4. Паркует машину и возвращает номер места

Parameters
vehicleNumberГосномер машины
cost[выходной] Стоимость парковки (рубли)

Алгоритм:

  2. Ищет машину по номеру
  3. Вызывает spot.leave() для получения времени стоянки
  4. Вычисляет стоимость: время * hourlyRate
  5. Обновляет выручку и возвращает значения
